Скрипт создания таблиц базы данных

Ниже приведён SQL-код для создания основных таблиц проекта.

-- Таблица пользователей
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Этот код необходимо выполнить в вашей СУБД (например, PostgreSQL, MySQL и т.д.) для создания структуры базы данных.
